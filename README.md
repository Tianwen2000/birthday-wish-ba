# 爸爸生日祝福网页

这是一个参考 `birthday-wish-xiaomei` 制作的单文件生日祝福页面，主题改为建筑工程师父亲：用施工图纸、塔吊、楼体、安全帽和平安灯表达爸爸在工地上的成就、担当与辛苦。

## 使用

直接双击打开 `index.html` 即可，无需安装依赖、无需联网或启动服务器。

页面交互：

- 点击“打开第一句祝福”，逐句解锁三段专属文案。
- 三段祝福完成后展示工地插画、彩带和生日配乐。
- 点击安全帽可以点亮或熄灭“平安灯”。
- 点击施工图区域会弹出随机祝福短句。

## 文案主题

- 肯定爸爸在工地上的日晒雨淋、认真负责与工程成就。
- 祝愿每一项工程顺利交付、每次进场平安、每天收工回家。
- 祝愿新一岁少些奔波操心，多些健康、休息与好心情。

页面全部内容都在 `index.html` 中，可直接修改标题、祝福对象和三段文案。
